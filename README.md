# AlquiYA!

> Servicio de alquileres de propiedades, habitaciones, y vehículos para la gente de Bahia Blanca.

Proyecto del equipo **Grupo-10** para _7513 · Proyecto de Desarrollo de Aplicaciones Web_
(Tecnicatura Universitaria en Programación Web y Móvil — DCIC — UNS).

AlquiYA! es una plataforma de alquiler de propiedades, habitaciones y
vehículos en Bahía Blanca, que conecta a clientes con propietarios
individuales e inmobiliarias. Ofrece una búsqueda simple y centralizada de
publicaciones, con filtros por tipo y precio, y mecanismos de valoración y
reportes para promover publicaciones confiables.

## Ficha del proyecto

| Aspecto                               | Descripción                                                                       |
| ----------------------                | ----------------------------------------------                                    |
| Problema                              | Ofrece alquieres de manera accesible y rapida para personas de bahia blanca       |
| Usuarios                              | Propietarios de casas y autos y clientes que buscan alquier casas/autos           |
| Funcionalidades núcleo                |                                                                                   |
| Reglas de negocio                     | cifrado de datos, creacion de publicaciones usuarios(propietarios y clientes)     |
| API externa                           | Google maps api, URL de la documentación yuso previsto                            |
